    Import a file

    Upload a CSV or .xlsx export, check it against the format's mapping rules, then load it. Nothing loads while any line is rejected unless you choose to load the valid lines.

    Datasets

    Workbooks kept as reference data. Each upload becomes a new version; mapping rules use the current version, and every import records which version it used.

    Backups and restore

    Every restore is written as one change, so it can be undone like any other. Restoring a snapshot over this application first takes a pre-restore snapshot.

    Put a slice back to an earlier point

    Rebuilt from the cell history: choose a slice and a moment, preview what would change, then restore.

    Put metadata back

    Dimensions and members, forms and reports as they were at a moment, or as a snapshot holds them. Members deleted since come back; renames, moves and property changes are undone; members added since are removed unless they hold data, which stays. A pre-restore snapshot is taken first.

    Snapshots

    A copy of the whole application (dimensions, security, forms, imports, datasets and data) kept in storage. One is taken every night when something changed.
